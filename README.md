# 📝 Todo Application

A dynamic and interactive Todo List application built using **HTML**, **CSS**, and **JavaScript**. This app allows users to add, mark tasks as complete, and delete tasks. It also saves tasks even after refreshing the page using **localStorage**.

## 🚀 Features

- **Add** new todo tasks with a simple input field and an **Add** button.
- **Strike-through** the task when it's marked as complete by clicking the checkbox.
- **Delete** tasks individually.
- **Input validation** to ensure that the user cannot add empty tasks.
- **Persistent data storage** using **localStorage**, so the tasks are saved even after a page refresh.
- User-friendly design with **interactive elements**.

## 🛠️ Technologies Used
- **HTML** – Structure of the Todo Application.
- **CSS** – Styling for a clean and intuitive UI.
- **JavaScript** – Functionality for adding, deleting, and marking tasks.
- **localStorage** – To persist tasks even after refreshing the page.

## 🎮 How to Use?
1. **Add** a new task by typing it into the input box and clicking the **Add** button.
2. Once a task is added, you can **mark it as complete** by clicking the checkbox, which will strike through the task.
3. To **delete** a task, click the **Delete** button next to the task.
4. All your tasks are stored in **localStorage** and will persist even after refreshing the page.
